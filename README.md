# 📊 Telecom Customer Churn Analysis Dashboard

## 📌 Project Overview

This project analyzes customer churn in a telecom company using Microsoft Excel. The objective is to identify the major factors contributing to customer attrition, monitor key business metrics, and build an interactive dashboard that enables business users to explore customer behavior and make data-driven decisions.

The project demonstrates the complete Excel analytics workflow including data cleaning, data integration, KPI calculation, pivot table analysis, and dashboard development.

---

## 🎯 Business Problem

Customer churn directly impacts revenue and customer acquisition costs. Understanding why customers leave helps organizations improve customer retention strategies.

This dashboard answers questions such as:

- What is the overall churn rate?
- Which contract types have the highest churn?
- Which payment methods are associated with more churn?
- Does internet service type affect churn?
- How do monthly charges influence customer retention?
- Which customer segments are more likely to leave?

## 📈 Business Insights

Some important insights generated from the dashboard include:

- Customers with Month-to-Month contracts have significantly higher churn.
- Customers using Fiber Optic internet services show higher churn rates.
- Monthly charges have a noticeable relationship with customer attrition.
- Customers without Tech Support are more likely to churn.
- Long-term contracts improve customer retention.
